Add your GitHub key

A key lets this browser change the shared stock. It’s stored only on this device, and every change is saved as a commit under your GitHub name. You need write access to dbulldesign/LaserStock.

  1. If you are dbulldesign (the repository owner): open new fine-grained token. Name it “LaserStock” and pick an expiry. Under Repository access change the default Public repositories (read-only) to Only select repositories → LaserStock. Then under Permissions → Repository permissions set Contents to Read and write. Generate it. (Already made one? Open it on your tokens page, choose Edit and change the same two settings.)
  2. If you are a collaborator: open new classic token (the public_repo box is already ticked), pick an expiry and generate it.
  3. Copy the key GitHub shows and paste it here.
